## Build and check the reports

From the project root:

~~~bash
python -m pip install -r requirements-report.txt
python src/reporting/build_reports.py --check
~~~

Both report versions share `tables/`, `figures/` and `references.tex`. Best means
and their standard deviations are bold in the comparison table. The builder
compiles each report twice and preserves the manually edited prose and authors.
A TeX distribution providing pdflatex, xelatex and ctex is required.

## Run the implementation checks

From `src/`:

~~~bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p "test_*.py" -v
python verify_metadata.py
~~~

Selected original-release arrays, manifests, all 72 pilot metadata records and
SQLite evidence are included. Heavy forecast/checkpoint artifacts are retained in
the original experiment directory and excluded from the lightweight code ZIP.
Metadata verification and full saved-output verification are different operations;
the detailed guide describes both without claiming omitted files are available.

claimed. New outputs are kept separate from frozen draft evidence.
