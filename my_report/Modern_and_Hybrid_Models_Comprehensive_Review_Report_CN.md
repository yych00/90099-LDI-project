## 1. 核心理论机制与实证复查总览

### 1.1 DLinear: 移动平均时序分解与跨通道权重共享机制
#### 1.1.1 趋势-季节项分解数学保和性与保真度
- **无残差保和性**：在 `SeriesDecomp` 模块中，$x = \text{Trend} + \text{Seasonal}$。实测重构误差 $\|(x_{\text{trend}} + x_{\text{seasonal}}) - x\|_\infty < 10^{-6}$，达到 IEEE 754 浮点单精度极限；
- **滑动平均内点线性保真度**：对于一阶多项式趋势 $x(t) = \alpha t + \beta$，在排除端点 padding 影响的内部区间，滑动平均结果与原信号绝对误差在双精度下为 **$2.84 \times 10^{-14}$**，严格证实滤波器的无偏性；
- **对称端点复制填充与因果抗未来泄漏**：
  两端填充长度满足 $p_{\text{front}} = \lfloor (k_{\text{ma}} - 1) / 2 \rfloor$，$p_{\text{end}} = k_{\text{ma}} - 1 - p_{\text{front}}$。末端时刻 $L-1$ 仅利用历史与当前观测 $x[:, L-1, :]$ 填充，感受野严格限制在 $(-\infty, L-1]$，绝无来自预测时域 $[L, L+H)$ 的任何信息泄漏；
- **高频谐波正交分离度**：
  实测将高频正弦振荡（周期 $T=4$，振幅 5.0）叠加至斜率 0.8 的线性趋势上，经过 $k=25$ 移动平均分解后，内点趋势项最大偏离理论线性趋势小于 **0.25**（高频振荡滤除率 $>95\%$），季节项与原始高频正弦振荡余弦相似度达到 **0.985**，实现物理正交解耦；
- **前置时序长度严格防御**：在 `forward` 中补充了 `x.size(1) == self.seq_len` 的防御断言，杜绝输入时序长度不匹配时底层全连接矩阵乘法抛出不可读运行时异常。

#### 1.1.2 跨通道权重共享 (individual=False) vs 通道独立 (individual=True)
- **通道共享模式 (individual=False)**：
  - 参数量：$2 \times (L \cdot H + H)$，与物理通道数 $C$ 完全解耦；
  - **置换等变性 (Permutation Equivariance)**：若将输入通道顺序任意置换 $\pi(C)$，输出张量通道顺序严格等价于 $\pi(Y)$，无任何跨通道错位；
  - **通道维度自适应性 (Channel Agnosticism)**：模型单次训练后，可直接无缝应用于 $C \in \{1, 4, 16, 64, 128\}$ 的任意通道输入，无需重新分配权重矩阵；
- **通道独立模式 (individual=True)**：
  - 参数量：$2 \times C \times (L \cdot H + H)$；
  - **通道间梯度严格隔离 (Gradient Isolation)**：若仅针对通道 $i$ 的输出构建损失求导，其余通道 $j \ne i$ 的私有卷积/全连接权重梯度严格为 0（无跨通道梯度串扰）。

### 1.2 PatchTST: 动态补齐覆盖率与反向传播梯度流验证
#### 1.2.1 动态切块与自适应末端补齐 (Dynamic Padding Coverage)
- **切块规则**：Patch 长度 $P=16$，滑动步长 $S=8$；
- **补齐公式核验**：
  若 $(L - P) \pmod S \neq 0$：
  $$N_{\text{patch}} = \lfloor (L - P) / S \rfloor + 2, \quad L_{\text{pad}} = (N_{\text{patch}} - 1) \cdot S + P - L$$
  若 $(L - P) \pmod S = 0$：
  $$N_{\text{patch}} = (L - P) / S + 1, \quad L_{\text{pad}} = 0$$
- **100% 时间步覆盖率**：在对 $L \in \{24, 30, 48, 50, 73, 96, 120, 168, 288, 336\}$ 的遍历中，所有原始历史时间步 $t \in [0, L-1]$ 的时步覆盖率达到严格的 **100.0%**（未遗漏任何时间点）；
- **短时序自适应降级**：当 $L < 16$ 时，模型自适应将 $P$ 缩放至 $L$，$S$ 缩放至 $\max(1, L//2)$，在 $L \in \{1, 2, 4, 8, 10, 15\}$ 边界下均能稳定前向与反向传播。

#### 1.2.2 全序列反向传播梯度流与 stride 盲区防御
- **梯度零死区率 0.0%**：在非整除窗口（如 $L=30, 50, 73, 100$）下，对全序列输入 $x$ 求偏导 $\nabla_x \mathcal{L}$，所有历史时间步 $t \in [0, L-1]$ 的梯度绝对值和均严格大于 0（死亡时间步数量为 0/L）；
- **末端时间步梯度累积一致性**：由于末端时间步 $L-1$ 被用于生成 $L_{\text{pad}}$ 个重复时间步以支撑最后一个 Patch 的感受野，反向传播过程中这 $L_{\text{pad}}$ 个填充点处的梯度全部无损累加至原始观测 $x[:, L-1, :]$ 上，强化了模型对临近当前时刻时序动态的注意力权重；
- **stride > patch_len 梯度空洞阻断**：实测证实，若允许 $S > P$（例如 $P=8, S=16$），在 48 个时步中有多达 23 个时间步落入两相邻切块间隙，导致梯度为 0（死区率近 $50\%$）。我们在 `__init__` 中增加了严格前置防御：`stride <= patch_len`，彻底消除观测盲区；
- **输入序列长度匹配保障**：在 `forward` 中增加 `x.size(1) == self.seq_len` 防御校验，杜绝因 $L > \text{seq\_len}$ 导致的末端关键时间步静默丢弃（截断前部 patch）以及 $L < \text{seq\_len}$ 导致的展平投影维度崩溃。

### 1.3 CNN–LSTM: 结构特征与参数量对历史窗口的不变性
#### 1.3.1 归纳偏置分工与长程压缩
- 前置 Conv1D ($k=3$) 充当局部时间带通滤波器，过滤白噪声并提取局部波形斜率；
- 后置 LSTM (hidden=64) 建模全局宏观演变，将长序列 $L$ 压缩为固定维度的最终隐藏状态 $h_L \in \mathbb{R}^{64}$；
- 线性投影头从 $h_L$ 直接多步映射至 $H \cdot C$，避免自回归单步递归累积误差；
- 增加了输入通道数 `x.size(-1) == self.num_channels` 的防御性校验，防御通道不一致引发的 Conv1d 内部底层抛错。

#### 1.3.2 参数量与历史窗口 L 的严格解耦 ($\mathcal{O}(1)$ 复杂度)
由于 LSTM 循环单元的权重仅取决于特征维度，且多步全连接头仅接收终态向量 $h_L$（维度恒为 64），CNN–LSTM 的全模型参数量具有极其优越的数学性质：
$$\frac{\partial P_{\text{CNNLSTM}}}{\partial L} = 0$$
在 $L \in [16, 336]$ 的所有历史窗口测试中，其在 Electricity 任务上的参数量恒定为 **61,504**。

#### 1.3.3 参数压缩与实证效果
- 相比于包含巨大 Flatten 层的纯一维卷积网络 1D-CNN (401,568)，CNN–LSTM 参数量缩减了 **84.68%**；在 Solar 高频任务上从 2,369,568 缩减至 186,304，缩减率达 **92.14%**；
- 在晚间尖峰负荷切片（Peak Slice）实测中，CNN–LSTM 取得 2.7072 MAE，优于纯循环模型与纯卷积模型，参数量对历史窗口长度的常数 $\mathcal{O}(1)$ 复杂度为高采样率时序部署提供了坚实保障。

## 2. 不同历史窗口下各子模块精确参数量的闭式解析对比矩阵

### 2.1 闭式解析公式定义
1. **DLinear (Shared)**：
   $$P_{\text{DLinear}}^{\text{Shared}}(L) = 2 \times H \times (L + 1)$$
2. **DLinear (Individual)**：
   $$P_{\text{DLinear}}^{\text{Indiv}}(L) = 2 \times C \times H \times (L + 1)$$
3. **CNN–LSTM**：
   $$P_{\text{CNNLSTM}} = (C_{\text{conv}} \cdot C \cdot K + C_{\text{conv}}) + 2 C_{\text{conv}} + 4 H_{\text{lstm}}(C_{\text{conv}} + H_{\text{lstm}} + 2) + (H \cdot C)(H_{\text{lstm}} + 1)$$
4. **PatchTST**：
   $$P_{\text{PatchTST}}(L) = (P d_{\text{model}} + d_{\text{model}}) + (N d_{\text{model}}) + e_{\text{layers}} \cdot \left[4 d_{\text{model}}^2 + 8 d_{\text{model}} + 2 d_{\text{model}} d_{\text{ff}} + d_{\text{ff}}\right] + H(N d_{\text{model}} + 1)$$

## 4. 关键发现与多智能体并发工程加固

1. **多智能体并发 SQLite WAL 治理**：
   - 为 `experiments.db` 统一启用了 `PRAGMA journal_mode = WAL` 与 30 秒 `busy_timeout`，消除了高并发读写下 `database is locked` 的偶发异常；
   - 在 `train.py` 中引入进程 PID 临时文件原子替换保存检查点（`tmp_path` + `os.replace`），防止多智能体并发写盘导致权重文件损坏。
2. **DLinear 训练轮数与帕累托表现**：
   - 在基准运行（ID 38）中，DLinear 训练 3 个 Epoch 即可迅速收敛至 2.7894 MAE（仅耗时 1.34 秒）；
   - 在延长训练至 18 个 Epoch 时，其测试集 MAE 进一步优化至 **2.5945**，与 PatchTST (2.5932) 和 CNN–LSTM (2.5940) 基本完全打平，同时其参数量（2,352）仅为后两者的 **3.09%** 和 **3.82%**！
3. **PatchTST 的长序扩展威力**：
   - 敏感性实验证实：当历史序列拓展至 168 小时时，Token 数量由 5 个拓展至 20 个，自注意力计算矩阵由 $25$ 个元素拓展至 $400$ 个元素（依然相比点级自注意力的 $28,224$ 节省 $98.58\%$），其 MASE 从 0.5053 显著降低至 **0.3969**，夺得全场绝对最高预测精度。
4. **CNN–LSTM 的抗突变能力**：
   - CNN 前置滤波在负荷尖峰切片上取得 2.7072 MAE，优于纯循环模型与纯卷积模型，参数量对历史窗口长度的常数 $\mathcal{O}(1)$ 复杂度为高采样率时序部署提供了坚实保障。
